# Architecture decision records

An ADR records one architectural decision: its context, the decision and its consequences. Once an ADR is accepted, it is never rewritten. A later ADR supersedes it, and the older one gets a note pointing forward. Each ADR also has a one-line entry in [`../decisions-log.md`](../decisions-log.md), so the log remains the chronological index.
