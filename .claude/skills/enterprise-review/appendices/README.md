# Appendices — ecosystem heuristics

Rules (Core §10): one file per ecosystem; loaded ONLY when a fired trigger
involves that ecosystem; hard cap 60 lines each; only non-obvious,
repo-relevant heuristics — restating general knowledge is prohibited;
subordinate to every protocol and to repo policy.

Empty at v1.0 by design: appendices are earned by eval failures, not written
speculatively. When a fixture exposes an ecosystem-specific miss, the fix may
be an appendix entry — cite the ledger row that motivated it.
